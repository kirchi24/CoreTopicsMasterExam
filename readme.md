# DAT24 – Masterprüfung Core Topics

Dieses Repository enthält die theoretische Ausarbeitung der 100 Core Topics für die Masterprüfung DAT24 im Jahr 2026.

## Ziel

- Pro Core Topic ungefähr 1 A4-Seite
- Kompakte, lernbare Zusammenfassungen
- Einheitlicher Aufbau
- Zentral kompilierbares PDF

## Repository-Struktur

- `main.tex`
  - Hauptdokument

- `sections/`
  - Enthält die Kapitel pro Themenbereich

- `assets/`
  - Bilder und Grafiken

## Kompilieren

```bash
latexmk -pdf main.tex
```
